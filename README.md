# LearnFlow — Componente React (Proyecto ADSO)

Repositorio del componente funcional en **React (JSX)** desarrollado para la plataforma de gestión académica **LearnFlow**.

## 🚀 Estructura del Proyecto

- `src/components/GestionAcademica.jsx`: Componente principal con manejo de estado (`useState`), formulario controlado, filtrado dinámico y comentarios explicativos en cada línea.
- `src/App.jsx`: Componente raíz de la aplicación.
- `src/main.jsx`: Punto de montaje en el DOM (`#root`).
- `src/App.css`: Estilos de la interfaz de usuario.

## 💻 Cómo ejecutar el proyecto localmente

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/juanma-studio-bit/learnflow-evidencia-react.git
   cd learnflow-evidencia-react
   ```
2. Instalar las dependencias:
   ```bash
   npm install
   ```
3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abrir en el navegador: `http://localhost:5173/`
